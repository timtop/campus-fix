# Five-minute demonstration guide

The assessment's first page also mentions a five-minute audiovisual PowerPoint presentation. A narrated PowerPoint/video has not been produced; this guide can be used to prepare that separate item if your lecturer confirms it is required alongside the single PDF.

0:00-0:40: Explain the manual complaint problem and CampusFix's purpose. Show the login screen.
0:40-1:40: Sign in as student, submit a location/category/priority request with evidence, and open its timeline.
1:40-2:40: Sign in as administrator. Find the request, assign the maintenance officer, and show user/category management.
2:40-3:40: Sign in as officer. Start work with a progress note, then complete the job. Return to student tracking and notifications.
3:40-4:30: Show status/category reports and CSV export. Explain database relationships and backend ownership/role checks.
4:30-5:00: Show actual passing test logs and screenshots. State the local verification result and the online deployment status honestly. If deployed later, show the real HTTPS URL and persistence check.
